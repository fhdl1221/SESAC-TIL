# 1. 배열

### 배열이란?
- 관련된 값들을 하나의 목록으로 묶어 관리
- 배열이름[인덱스]
- 인덱스 : 배열에서 위치를 나타내는 번호로 0부터 시작
- 배열도 객체이므로 프로퍼티가 존재

### 배열 메소드
- push() : 배열의 끝에 요소를 추가하고 새 길이 반환
- pop() : 배열의 끝 요소를 제거하고 제거한 요소 반환
- unshift() : 배열의 맨 앞에 요소 추가하고 길이 반환
- shift() : 배열의 맨 앞 요소 제거하고 제거한 요소 반환
- indexOf() : 값이 처음 나오는 인덱스 반환
- includes() : 값이 있으면 true, 없으면 false 반환

### forEach()
- 배열의 요소를 하나씩 전달
- 콜백을 호출할 때 현재 요소와 현재 인덱스를 전달
- 콜백함수의 반환값을 모아주지 않는다. 반환값은 undefined

### map()
- 각 요소를 콜백의 반환값으로 바꾼 결과를 새 배열로 만들어준다
- 원본 배열에 영향을 주지 않는다


### filter()
- 콜백 함수의 반환 결과가 true인 요소만 모아 새 배열을 만든다
- 조건을 만족하는 요소가 없으면 빈 배열 반환

### find()
- 조건에 맞는 첫번째 요소를 반환
- 조건에 맞는 요소가 없으면 undefined 반환
- undefined를 반환하는 경우가 있을 수 있기 때문에 안정적인 객체 접근 필요(?.)

### some()
- 조건에 맞는 요소가 하나라도 있는지 확인
- 불리언 값 반환

### every()
- 모든 요소가 조건에 맞는지 확인
- 불리언 값 반환

### sort()
- 기본 sort()는 숫자를 문자열로 보고 순서 정렬
- 원본 배열을 정렬

```js
numbers.sort((a, b) => a -b); // 오름차순
numbers.sort((a, b) => b - a); // 내림차순
```
- 반환값이 음수 : a를 앞에 정렬
- 반환값이 양수 : b를 앞에 정렬
- 0 : 이 비교 기준에서 같은 순위로 취급

### reduce()
- 누적할 때 사용
- 반환값을 받아 다음 호출로 넘겨준다
- reduce(콜백함수, 초기값)

# 2. 표준 빌트인 객체

## String 표준 빌트인 객체
문자열은 변경할 수 없는 값이므로 메서드를 실행해도 원본은 바뀌지 않는다

### trim()
- 문자열 앞뒤 공백 제거

### toLowerCase(), toUpperCase()
- 영문 대소문자 정리

### indexOf() 
- 검색어가 시작하는 인덱스 반환
- 찾지 못하면 -1 반환

### includes()
- 검색어가 들어있는지 확인
- 불리언 값 반환

### slice()
- 문자열에서 필요한 부분 가져오기
- slice(시작인덱스, 끝인덱스)
- 끝인덱스 생략 시 문자열 끝까지 가져옴

### lastIndexOf('.')
- 문자열에서 마지막 마침표(.)의 인덱스를 찾는다

### split()
- 문자열을 배열로 나눈다

## Math 표준 빌트인 객체
수학 계산 기능을 제공하며 new로 만들지 않고 Math.메서드()로 바로 사용한다

1. 반올림.내림.올림
### round()
- 소수점 이하를 반올림
### floor()
- 주어진 수보다 크지 않은 최대 정수(내림)
### ceil()
- 주어진 수보다 작지 않은 최소 정수(올림)

2. 랜덤 값
### random()
- 실행할 때마다 0이상 1미만의 임의의 실수 반환
