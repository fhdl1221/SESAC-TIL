# JavaScript 함수 · 스코프 정리

# 1. 함수 선언문

## 함수란?

- 특정 작업을 재사용할 수 있도록 묶은 코드

## 매개변수 vs 인수

매개변수(Parameter) : 함수를 정의할 때 받는 변수

인수(Argument) : 함수를 호출할 때 전달하는 실제 값

- 매개변수는 함수 내부에서만 사용하는 지역 변수

## 기본값

- 인수를 전달하지 않거나 `undefined`를 전달하면 기본값 사용

# 2. return

## return의 역할

- 함수의 결과값을 호출한 곳으로 반환한다

- 반환된 값은 변수에 저장하거나 다른 연산에 사용할 수 있다

## return 특징

- `return`을 만나면 함수가 즉시 종료된다

- `return`이 없거나 값 없이 쓰면 `undefined`를 반환한다

## Early Return

- 조건이 맞지 않으면 먼저 `return`으로 함수를 종료하는 방식

# 3. 함수 표현식

## 함수 표현식

- 함수를 변수에 저장하는 방식

- `const hi = function() { ... }` 형태

## 호이스팅 차이

함수 선언문 : 선언 전에 호출 가능

함수 표현식 : 선언 전에 호출 불가

- 함수 선언문은 호이스팅된다

- 함수 표현식은 초기화 이후에만 사용할 수 있다

# 4. 함수는 일급 객체

## 함수도 값이다

- 변수에 저장 가능

- 객체의 프로퍼티로 저장 가능

- 다른 함수의 인수로 전달 가능

- 함수의 반환값으로도 사용 가능

일급 객체 특징

- 전달하고 반환할 수 있는 값처럼 취급된다

# 5. 콜백 함수

## 콜백 함수

- 다른 함수에 전달되어 필요한 시점에 실행되는 함수

## 고차 함수

- 함수를 매개변수로 받는 함수

- 실행 시점은 고차 함수가 결정하고, 실행 내용은 콜백 함수가 결정한다

## 활용 예시

- `sort()`에 정렬 기준 함수를 전달하여 오름차순 정렬

# 6. 스코프

## 스코프

- 변수를 사용할 수 있는 범위

### 종류

- 함수 스코프 : 함수 안에서 선언한 변수는 함수 밖에서 접근 불가

- 블록 스코프 : `{}` 안에서 선언한 `let`, `const`는 블록 밖에서 접근 불가

# 7. 스코프 탐색

## 변수 탐색

- 가까운 스코프의 변수를 먼저 찾는다

- 내부에 같은 이름이 있으면 바깥 변수는 가려진다(Shadowing)

## 렉시컬 스코프

- 함수는 정의된 위치의 스코프를 기억한다

- 호출 위치가 아니라 정의 위치를 기준으로 변수를 찾는다

## 핵심 포인트

- `var`는 반복문 밖 변수와 같은 변수를 공유한다

- `const` 객체는 객체 자체 재할당은 불가, 프로퍼티 수정은 가능
