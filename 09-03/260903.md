## 1. HTML 기본 개념

**HTML(HyperText Markup Language)**은 웹 문서의 **구조와 의미를 표현하는 마크업 언어**

### 태그, 요소, 속성

```html
<p class="description">안녕하세요.</p>
```

- **태그(Tag)**: HTML 구조를 표시하는 문법
- **요소(Element)**: 시작 태그부터 종료 태그까지 하나의 구성 단위
- **속성(Attribute)**: 요소에 추가적인 정보를 제공
- **콘텐츠(Content)**: 시작 태그와 종료 태그 사이의 실제 내용

속성은 일반적으로 다음과 같이 작성한다

```html
속성="값"
```

### 요소 중첩

HTML 요소 안에 다른 요소를 넣을 수 있다

```html
<div>
    <h1>제목</h1>
    <p>내용</p>
</div>
```

- `div` → 부모 요소
- `h1`, `p` → 자식 요소

### 빈 요소(Void Element)

종료 태그가 필요하지 않은 요소도 있다

```html
<br />
<hr />
<input type="text" />
```

## 2. 제목, 문단, 텍스트, 목록

### 제목

```html
<h1>가장 중요한 제목</h1>
<h2>하위 제목</h2>
<h3>더 작은 제목</h3>
```

`h1 ~ h6`은 단순히 글자 크기를 지정하는 것이 아니라 **문서의 제목과 계층 구조를 표현**

### 문단과 줄바꿈

```html
<p>문단입니다.</p>

<br />

<hr />
```

- `<p>` → 문단
- `<br>` → 줄바꿈
- `<hr>` → 주제 또는 내용 구분

### 텍스트 의미 표현

```html
<b>굵게</b>
<strong>중요한 내용</strong>

<i>기울임</i>
<em>강조</em>

<mark>강조 표시</mark>
<del>삭제된 내용</del>
```

특히 `strong`, `em`은 단순한 모양보다 **콘텐츠의 의미**를 표현한다

### 목록

```html
<ul>
    <li>HTML</li>
    <li>CSS</li>
</ul>
```

```html
<ol>
    <li>HTML 공부</li>
    <li>CSS 공부</li>
</ol>
```

- `<ul>` → 순서 없는 목록
- `<ol>` → 순서 있는 목록
- `<li>` → 목록의 항목

## 3. 레이아웃과 시맨틱 태그

### `<div>`와 `<span>`

```html
<div>큰 영역을 묶음</div>

<p>
    <span>문장 일부</span>
</p>
```

| 요소   | 특징        | 용도             |
| ------ | ----------- | ---------------- |
| `div`  | 블록 요소   | 큰 영역 그룹화   |
| `span` | 인라인 요소 | 문장 일부 그룹화 |

둘 다 **특별한 의미는 없으며**, 단순한 그룹화가 필요할 때 사용한다

### 시맨틱 태그

시맨틱 태그는 태그 이름만 보고도 **해당 영역의 역할을 이해할 수 있도록 의미를 부여하는 태그**

```html
<header>머리말</header>
<nav>내비게이션</nav>

<main>
    <section>주제별 영역</section>
    <article>독립적인 콘텐츠</article>
    <aside>부가 콘텐츠</aside>
</main>

<footer>하단 정보</footer>
```

| 태그      | 역할               |
| --------- | ------------------ |
| `header`  | 머리말             |
| `nav`     | 내비게이션         |
| `main`    | 핵심 콘텐츠        |
| `section` | 주제별 콘텐츠 영역 |
| `article` | 독립적인 콘텐츠    |
| `aside`   | 부가 콘텐츠        |
| `footer`  | 하단 정보          |

**원칙**

> 의미가 있는 영역 → 시맨틱 태그
> 단순한 그룹화 → `div`

시맨틱 태그는 HTML 구조를 이해하기 쉽고, 접근성에도 도움이 된다

## 4. `id`와 `class`

### `id`

요소를 **고유하게 식별**할 때 사용한다

```html
<section id="intro">
    <h2>소개</h2>
</section>
```

페이지 내부 이동에도 사용할 수 있다

```html
<a href="#intro">소개로 이동</a>
```

```text
href="#intro"
      ↓
id="intro"
```

### `class`

여러 요소를 **그룹화**할 때 사용한다

```html
<p class="description">첫 번째 설명</p>
<p class="description">두 번째 설명</p>
```

주로 CSS에서 여러 요소에 동일한 스타일을 적용할 때 사용한다

```text
id    → 하나의 요소를 식별
class → 여러 요소를 그룹화
```

## 5. 링크

링크는 `<a>` 태그를 사용한다

```html
<a href="https://example.com">사이트 이동</a>
```

주요 속성:

| 속성     | 역할           |
| -------- | -------------- |
| `href`   | 이동할 주소    |
| `target` | 링크를 열 위치 |

새 탭에서 열기

```html
<a href="https://example.com" target="_blank"> 사이트 이동 </a>
```

페이지 내부 이동

```html
<a href="#skills">기술 보기</a>

<section id="skills">
    <h2>기술</h2>
</section>
```

## 6. Form

`form`은 사용자의 입력을 받고 데이터를 서버로 전달할 때 사용한다

```html
<form action="/guestbook" method="post">...</form>
```

| 속성     | 역할                 |
| -------- | -------------------- |
| `action` | 데이터를 전달할 주소 |
| `method` | 데이터 전송 방식     |

### GET vs POST

```text
GET
→ 데이터를 URL에 포함하여 전송

POST
→ 요청 본문(body)에 데이터를 담아 전송
```

### 기본 폼 요소

```html
<label for="user-id">아이디</label>
<input id="user-id" name="userId" type="text" required />
```

```html
<select name="track">
    <option value="backend">백엔드</option>
    <option value="frontend">프론트엔드</option>
</select>
```

```html
<textarea name="memo" placeholder="내용을 입력하세요"></textarea>
```

```html
<button type="submit">제출</button> <button type="reset">초기화</button>
```

주요 태그:

| 태그       | 역할                     |
| ---------- | ------------------------ |
| `form`     | 입력 및 데이터 전송 영역 |
| `fieldset` | 폼 요소 그룹화           |
| `legend`   | `fieldset` 제목          |
| `label`    | 입력 요소의 설명         |
| `input`    | 다양한 사용자 입력       |
| `select`   | 선택 목록                |
| `option`   | 선택 항목                |
| `textarea` | 여러 줄 입력             |
| `button`   | 버튼                     |

## 7. Form에서 중요한 속성

```html
<input id="user-id" name="userId" type="text" value="gildong" required />
```

### `id` / `name` / `value` / `for`

```text
label for
    ↓
input id
```

`label`의 `for`와 `input`의 `id`가 연결된다

```html
<label for="user-id">아이디</label> <input id="user-id" />
```

반면 `name`은 **폼 데이터를 서버에 전달할 때 사용하는 이름**이다

```html
<input name="userId" />
```

```text
id    → 요소 식별
for   → label과 input 연결
name  → 서버로 전달할 데이터 이름
value → 전달할 값
```

### 자주 사용하는 입력 속성

```text
required    → 필수 입력
placeholder → 입력 안내 문구
checked     → 기본 선택
selected    → 기본 선택된 option
disabled    → 비활성화
readonly    → 읽기 전용
min / max   → 최소/최대값
minlength / maxlength → 문자열 길이 제한
```

## 8. HTML 기본 개념 핵심 정리

```text
HTML
→ 웹 문서의 구조와 의미를 표현

문서 구조
→ html / head / body

콘텐츠
→ h1~h6 / p / br / hr

목록
→ ul / ol / li

그룹화
→ div / span

시맨틱
→ header / nav / main / section
   article / aside / footer

링크
→ a / href / target / rel

폼
→ form / action / method
→ label / input
→ select / option
→ textarea / button

속성
→ id / class
→ id ↔ for
→ name → 서버에 전달할 이름
→ value → 전달할 값
```
