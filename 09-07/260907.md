# JavaScript 개념 정리

## 1. 연산자

### 산술 연산자

```js
+  -  *  /  %  **
```

→ 기본적인 숫자 계산에 사용

### 증감 연산자

```js
++  // 1 증가
--  // 1 감소
```

* `++i` → 먼저 증가
* `i++` → 사용 후 증가

### 비교 연산자 

```js
==   !=    // 값만 비교
===  !==   // 값 + 타입 비교
>  <  >=  <=
```

→ 결과는 `true` 또는 `false`

**일반적으로 `===` 사용**

### 논리 연산자

```js
&&  // AND : 모두 true
||  // OR  : 하나라도 true
!   // NOT : 반대
```

# 2. 조건문

### if

```js
if (조건) {
    // true
} else {
    // false
}
```

여러 조건은 `else if` 사용

### switch

하나의 값을 여러 경우로 나눌 때 사용한다

```js
switch (value) {
    case "A":
        break;
    case "B":
        break;
    default:
}
```

# 3. 반복문

### for

반복 횟수가 명확할 때 사용한다

```js
for (초기화; 조건식; 증감식) {
    // 반복
}
```

### while

조건이 `true`인 동안 반복한다

```js
while (조건) {
    // 반복
}
```

→ **반복을 멈출 조건이 중요할 때** 사용

### continue / break

```js
continue; // 이번 반복만 건너뜀
break;    // 반복문 종료
```

# 4. 객체

객체는 **key와 value로 구성된 데이터 묶음**

* `key` → 속성의 이름
* `value` → 속성의 값
* 함수가 들어간 프로퍼티 → **메서드**

### 프로퍼티 접근

```js
user.name
user["name"]
```

변수를 이용해 key를 접근할 때는 `[]` 사용

```js
const key = "name";
user[key];
```

### 프로퍼티 추가 / 수정 / 삭제

```js
user.age = 20;       // 추가 또는 수정
delete user.age;     // 삭제
```

`const` 객체라도 **내부 프로퍼티는 수정 가능**하지만 객체 자체를 재할당할 수는 없다

### 객체 순회

```js
for (const key in user) {
    console.log(user[key]);
}
```

→ 객체의 프로퍼티를 하나씩 확인한다
