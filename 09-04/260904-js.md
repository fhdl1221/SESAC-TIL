# JavaScript 개념 정리

## 1. 변수

- `let` → 값을 **재할당 가능**
- `const` → **재할당 불가능**
- `var` → 오래된 방식이므로 일반적으로 `let`, `const` 사용
- 변수명은 보통 **camelCase** 사용

---

## 2. 기본 타입

JavaScript는 **동적 타입 언어** → 변수의 타입이 값에 따라 결정

| 타입        | 의미                 |
| ----------- | -------------------- |
| `Number`    | 숫자                 |
| `String`    | 문자열               |
| `Boolean`   | `true` / `false`     |
| `null`      | 의도적으로 값이 없음 |
| `undefined` | 값이 할당되지 않음   |

```js
typeof value;
```

→ 값의 타입 확인

---

## 3. 템플릿 리터럴

백틱(`)을 사용해 문자열을 작성한다
→ 문자열 안에 변수나 표현식을 쉽게 넣을 수 있다

---

## 4. 타입 변환

### 암묵적 변환

JavaScript가 **자동으로 타입을 변환**한다

```js
10 + "20"; // "1020"
10 - "5"; // 5
```

특히 `+`는 문자열이 포함되면 문자열 연결로 동작

### 명시적 변환

개발자가 직접 변환

```js
String(10); // "10"
Number("10"); // 10
Boolean(1); // true
```

추가로:

```js
parseInt("10");
parseFloat("10.5");
```

→ 문자열을 정수/실수로 변환

---

## 5. Truthy / Falsy

조건문에서 값이 `true` 또는 `false`처럼 평가된다

**Falsy 6가지**

```text
false
0
""
null
undefined
NaN
```

→ 이외의 값은 기본적으로 **Truthy**로 평가된다
