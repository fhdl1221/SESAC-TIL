# CSS 개념 정리

## 1. 기본 문법

```css
선택자 {
    속성: 값;
}
```

* **선택자**: 스타일을 적용할 대상
* **속성**: 변경할 내용
* **값**: 적용할 값

---

## 2. 선택자

```css
p {}              /* 태그 */
.text {}          /* 클래스 */
#title {}         /* 아이디 */
div p {}          /* 후손 */
div > p {}        /* 자식 */
input[type="text"] {}  /* 속성 */
```

* `.class` → 여러 요소에 적용
* `#id` → 특정 요소에 적용
* `A B` → A 안의 모든 B
* `A > B` → A의 바로 아래 B

**우선순위:** 태그 < 클래스 < 아이디

---

## 3. 가상 클래스

```css
button:hover {}   /* 마우스를 올렸을 때 */
button:active {}  /* 클릭하는 동안 */
input:checked {}  /* 체크된 상태 */
```

요소의 **상태에 따라 스타일을 적용**

---

## 4. Box Model

```text
margin
 └ border
    └ padding
       └ content
```

* `content` → 실제 내용
* `padding` → 안쪽 여백
* `border` → 테두리
* `margin` → 바깥쪽 여백

```css
box-sizing: border-box;
```

→ `width`, `height`에 **padding과 border를 포함**해서 계산

---

## 5. Flexbox

```css
display: flex;
justify-content: center;
align-items: center;
```

* `display: flex` → Flex 레이아웃 사용
* `justify-content` → **주축 정렬**
* `align-items` → **교차축 정렬**
* `flex-wrap: wrap` → 공간이 부족하면 줄바꿈

→ **요소를 한 방향으로 배치할 때 사용**

---

## 6. Grid

```css
display: grid;
grid-template-columns: 1fr 1fr 1fr;
gap: 10px;
```

→ 요소를 **행과 열 형태로 배치**할 때 사용

---

## 7. Position

```css
.parent {
    position: relative;
}

.child {
    position: absolute;
    top: 10px;
    left: 10px;
}
```

* `relative` → 위치의 **기준점**
* `absolute` → 기준점을 기준으로 **원하는 위치에 배치**

---

## 8. Transition

```css
transition: all 0.3s ease;
```

→ CSS 속성 변화를 **부드럽게** 만든다

보통 `:hover`와 함께 사용
